# 핸즈온 커리큘럼 보완안

레퍼런스(260709~260730 핸즈온 1~4차 PPT, 핸즈온 LMS 화면, 원데이 교육 5-1·5-2)를 검토하고, **"수강생 각자가 학업·사업·업무용 자동화 도구를 4주 안에 완성한다"**는 목표에 비춰 부족한 부분을 정리했습니다. 보완 내용은 모두 수업 PT(`src/content/week1~4.json`)와 웹앱에 반영되어 있습니다.

## 3. 운영 방식 보완 (웹앱)

| 기존 | 보완 |
|---|---|
| 핀코드 하나로 LMS 접속, 브라우저 저장 | **기수별 입장 코드 + 개인 아이디/비밀번호**, 서버 DB 저장 → 다른 PC에서도 이어서 작업 |
| LMS 5단계(아이디어·워크플로우·우선순위·프롬프트·제출) | **6단계**: 아이디어 → 워크플로우 → 우선순위 → AI 명령서 → **제작 기록** → **발표 PT** |
| 진도 공유를 PPT 슬라이드에 직접 입력 | 웹앱 '진도공유' 탭(이번 주 진행·다음 주 목표·지원 필요) + **강사 피드백**이 수강생 홈에 표시 |
| 공정표는 외부 링크(bit.ly)로 별도 입력 | 제작 기록·성과가 워크스페이스 안에 쌓이고 CSV로 한 번에 내보내기 |
| 스크린샷·영상 보관 공간 없음 | **자료실**(이미지·동영상·PDF 업로드, 최대 200MB) → 제작 기록·발표에 첨부 |
| 발표 자료를 따로 만들어야 함 | 워크스페이스 내용이 **발표 슬라이드로 자동 변환**, 전체화면 발표 + 기수 갤러리 공유 |
| 기수가 끝나면 데이터 확인 어려움 | 관리자 대시보드에서 **모든 기수 누적 관리**(종료 기수 보관, 단계별 완료율, CSV) |

## 4. 강사가 추가로 준비하면 좋은 것

- **실습용 샘플 데이터 세트**: 학업형(논문 PDF 3편), 사업형(거래처 엑셀 5개·견적서 양식), 업무형(기존 YBM 실습 데이터) — 주제를 못 정한 수강생이 바로 시작할 수 있도록.
- **2주차 시연 영상**: 형태별(HTML·Python·데스크톱) 첫 요청부터 실행까지 3분 녹화본 — 수강생 PC 환경 차이로 막힐 때 대체 자료.
- **회사 보안 정책 확인**: 외부 AI에 넣을 수 있는 자료의 범위를 1주차에 공지.
- **에이전트 AI 구독 안내**: 유료 계정이 필요하므로 과정 시작 전 공지(무료 대안: Gemini CLI 등은 기능·한도가 다름).
